# Производная в действии — пространственная лаборатория V3

**10:40.064**, 10 глав, **50 камерных планов и 122 речевых события**. Урок построен как полноэкранная 3D-лаборатория Three.js: измерительная дорога с автомобилем, кофейный стол, геометрические установки, механизм зависимостей и вертикальная шахта мяча. Камера перемещается вокруг крупных предметов, меняет высоту и масштаб; белые поверхности чередуются с тёмными зонами. Формулы и короткие подписи появляются рядом с текущим действием.

**Сценарий и голос V2 сохранены без изменений.** Это прежняя русская озвучка Gemini 2.5 Pro TTS / Puck, прежняя музыка и звуковые акценты. V3 не генерирует речь заново и не меняет её темп. Все десять WAV в двух папках и оба голосовых манифеста сохраняют исходные SHA-256. Общая длительность включает существующие 2.5 секунды в конце каждой главы.

При подготовке V2 речь была ускорена в **1.1 раза без изменения высоты голоса**. Громкость выровнена одним постоянным коэффициентом на главу: цель RMS −21 dBFS, максимум усиления +4 dB, ограничение пиков −1.5 dBFS. Фактический RMS готовых глав — от −21.78 до −21.00 dBFS; формат — PCM WAV, 24 kHz, mono, 16 bit.

## Пространство, математика и синхронизация

Один общий `createDerivativeRenderer` в `client/src/lesson/DerivativeScene.tsx` используется React-плеером и экспортом HyperFrames. Положение камеры, объектов, колёс и графических маркеров вычисляется из времени фильма: пауза и произвольная перемотка не зависят от предыдущего кадра. `sceneTheme.ts` согласует светлую или тёмную зону с цветом формул.

Поле `voice.json → chapters[].beatTimes` задаёт пять измеренных начал реплик каждой главы. `sceneProgressAt` переводит реальные секунды в пять канонических интервалов. `labCues.ts` уточняет внутри них 122 события по словам готовой речи; `labFormula.ts` использует те же события для формул и ответов. Например, отметки 1/4/9, интервалы h = 0,1 и 0,01, температура 69 °C и нулевая скорость мяча появляются на соответствующих словах. При отсутствии корректных измеренных начал реплик сервер использует пропорциональный сценарный тайминг; поставляемый урок содержит измеренные времена.

Автомобиль движется по прямой согласно s(t) = t², а парабола отдельно записывает координату во времени. Касательная к температурной кривой даёт локальный прогноз, не точный закон охлаждения. У мяча H(t) = −t² + 4t максимум при t = 2 и H = 4; соседняя кубическая кривая показывает, почему нулевая производная сама по себе не гарантирует экстремум. Камера приближается к объясняемой детали, сохраняя числовые координаты графика.

## Просмотр

В кабинете преподавателя занятие с темой «Производная» или «Дифференцирование» открывает фильм при старте пары. Предпросмотр: `/teach?preview=derivative`; он не запускает занятие и перекличку.

Пробел — пауза; стрелки — ±10 секунд; `F` — полный экран; `M` — звук. Браузер может потребовать нажатие «Продолжить» для первого воспроизведения. Позиция сохраняется отдельно для каждого занятия.

## Инструмент генерации голоса

Для просмотра и сборки V3 этот шаг не требуется. Следующие команды предназначены для будущего отдельного изменения озвучки; после новой генерации необходимо заново проверить времена реплик и речевых событий.

Ключ задаётся серверной переменной `GEMINI_API_KEY` либо файлом `DATA_DIR/secrets/google-ai.key` с правами `600`. По умолчанию `DATA_DIR=data`. Ключ не нужен для воспроизведения уже подготовленного урока.

**FFmpeg нужен только генератору нового голоса** для обработки темпа. Готовый урок воспроизводится без установленного FFmpeg. Генератор проверяет доступность инструмента до отправки платного запроса Google.

```sh
npm run cinema:voice -- --dry-run
npm run cinema:voice
```

Модель по умолчанию — `gemini-2.5-pro-preview-tts`, голос — `Puck`; настройки: `GEMINI_TTS_MODEL`, `GEMINI_TTS_VOICE`. Для одной главы: `--chapter=the-moment`; для принудительного повтора: `--force`. Генерация последовательная, с возобновлением: готовые главы с неизменными текстом, моделью, голосом и версией обработки берутся из кеша. Новые запросы могут расходовать квоту Google.

Каждая новая запись проходит тот же воспроизводимый процесс: Google WAV → FFmpeg `atempo=1.1` → PCM 24 kHz mono → постоянный gain с указанными ограничениями → итоговый WAV. Версия кеша — `cinema-russian-v2-action-tempo110`; `voice.json → tempo` хранит значение `1.1`. Измеренные времена реплик должны соответствовать уже обработанному аудио.

Результат сохраняется в `DATA_DIR/cinema/derivative/`: WAV и `voice.json`. Если действительного приватного манифеста нет, стандартный урок использует включённую в проект папку `content/derivative/voice/`. Приватный манифест имеет приоритет, включая незавершённую генерацию. После изменения сценария потребуется соответствующая озвучка.

## Доступ и воспроизведение

Манифест `/api/cinema/derivative` и аудио доступны только вошедшим преподавателям и администраторам. Аудио передаётся через защищённый маршрут с поддержкой Range. Пути файлов не публикуются; неверные ID, выход из папки и символические ссылки отвергаются. Ключ отправляется только в заголовке HTTPS-запроса Google из серверного генератора; в клиент и сборку он не включается. Не помещайте ключ в переменные с префиксом `VITE_` или в архив проекта.

## Композиция HyperFrames

```sh
npm run cinema:composition
cd films/derivative
npx hyperframes preview --background
```

Команда собирает HTML-композицию и локальные медиа в `films/derivative/` из того же рендерера, формул, тем и фактического голосового тайминга. GLB и его атрибуция копируются вместе со звуком и шрифтами. Экспорт MP4 выполняется отдельно средствами HyperFrames.

Фактические результаты проверок публикуются в [VALIDATION.md](VALIDATION.md); описание устройства V3 не заменяет итоговый протокол проверки.
